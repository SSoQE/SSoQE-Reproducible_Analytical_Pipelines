## 🌿 About the lesson

This is a new lesson in the SSoQE 2026 programme. It will bring together the coding, reproducibility, project-management, and functional-programming practices introduced earlier in the week and show how an analysis can be expressed as an explicit, dependency-aware pipeline.

## 🎯 Planned learning goals

The final teaching materials should enable participants to:

- separate immutable inputs, reusable functions, orchestration, and derived outputs;
- represent analytical dependencies explicitly;
- rerun work from a clean session without hidden interactive state;
- understand how caching and selective rebuilding can improve efficiency without concealing stale results;
- design pipelines that are inspectable, restartable, and suitable for collaboration.

## 🚧 Repository status

This repository is the starting point for the new lesson. The pipeline framework, teaching data, exercises, dependency environment, rendering workflow, maintainers, and licensing information have not yet been selected and must be documented when the lesson is designed.

The current Quarto presentation and example exercise are inherited template placeholders. Do not infer a specific pipeline framework merely because another SSoQE repository contains related code or tracked metadata.
